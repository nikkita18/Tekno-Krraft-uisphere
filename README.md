## 🌟 Highlights & Key Features

### 1. 🌐 3D Interactive UI Sphere Canvas
- **Fibonacci Point Cloud**: 320 mathematically positioned nodes rendered with authentic Google brand color halos (`#4285F4`, `#EA4335`, `#FBBC04`, `#34A853`).
- **3D Gyroscope Orbital Rings**: Tilted elliptical latitude/equator rings with dashed glowing strokes orbiting the sphere in 3D perspective.
- **Physics & Gestures**: Smooth mouse drag & mobile touch inertia, velocity damping, and click-to-pulse shockwave waves.
- **Interactive Mode Switcher**: Instant switching between `✦ Fibonacci`, `🌐 Constellation`, and `⚛️ Quantum` modes.
- **Floating Telemetry Badges**: Ambient frosted glass badges displaying festival metrics.

### 2. 🤖 Radiant Gemini AI Concierge
- **Kinetic Gradient Border**: Custom CSS `@property` conic-gradient border continuously rotating with smooth Google hues.
- **Interactive Assistant**: Natural language question answering synthesized directly from the GDG ITER festival corpus with streaming typewriter effect.
- **Quick-Prompt Suggestions**: One-click prompt pills for prize pool breakdowns, prerequisites, and schedules.

### 3. 🎫 3D Holographic Delegate Pass Generator
- **Gyroscopic Tilt Parallax**: Real-time 3D tilt tracking cursor motion with dynamic holographic foil rainbow reflections.
- **Pass Flip Mechanic**: Flip pass to reveal campus Wi-Fi credentials (`ITER_GDG_GUEST`) and SHA-256 access tokens.
- **Live Personalization & Export**: Live attendee name and track customization with high-resolution vector SVG download.

### 4. 📅 3-Day Schedule & Itinerary Planner ("My Plan")
- **3-Day Navigation**: Day 01 (Kickoff & Cloud/Web3), Day 02 (AI Hack & System Design), Day 03 (Code Finals & Awards).
- **Domain Filter & Live Search**: Category chips (Keynote, Workshop, Hackathon, Competition, Talk, Gaming) and real-time search.
- **Personal Itinerary Drawer**: Bookmarking sessions updates the navbar counter badge in real time with `.ics` calendar sync.

### 5. 🛠️ Interactive Developer Suite
- **Campus Architectural Blueprint**: Interactive map of ITER computing facilities (Bansuri Guru Lab 3, Auditorium 101, SAC Arena).
- **Hack Sprint Squad & Prize Calculator**: Interactive simulator to calculate potential earnings from the ₹2,50,000 prize pool.
- **TK-SHELL Terminal**: Floating retro-developer CLI with commands (`help`, `tracks`, `schedule`, `register`, `prizes`, `gemini <q>`).
- **Tactile Web Audio Synthesizer**: Subtle harmonic synth feedback for button interactions with a toggle in the navbar.

## 🚀 Getting Started

### Prerequisites
Any modern web browser supporting modern Canvas 2D, CSS Backdrop Filter, and ES6 Modules.

### Running Locally
You can serve the project using Python's built-in HTTP server:

```bash
# Clone the repository
git clone https://github.com/nikkita18/Tekno-Krraft-uisphere.git
cd Tekno-Krraft-uisphere

# Run with Python HTTP server
python -m http.server 3000
```

Open your browser and navigate to:
```
http://localhost:3000/
```
